# MAP01~03 부산 3D 지도 (지형·바다 / 일차별 루트 / 장소 핀) 3D 설계도

버전: v1.0 — 2026-11-10 — 최초 작성 (설계·모델링 모두 Claude. 지도는 실제 자료로 만들기 때문에 ChatGPT 설계도를 거치지 않음)
상태: 검토
폴더: `busan-3d/assets/MAP01_BusanMap/`

## 1. 개요
| 항목 | 내용 |
|---|---|
| 등장 장면 | 장면 전환 전체. 정류장 사이를 이동할 때 지도 위에서 루트가 그려진다 |
| 화면에서의 역할 | 여행자가 하루 동안 부산의 어디를 어떤 순서로 지나는지 한눈에 보여준다 |
| 등급 | H (화면 전체를 채움) |
| 가장 가까운 카메라 거리 | 약 0.3 unit (= 실제 3 km 범위를 화면에 담는 정도) |
| 화면 점유율 | 최대 100 % |

## 2. 핵심 특징
- **지켜야 할 것**
  1. 해안선과 섬(영도, 오륙도, 동백섬)의 모양. 실제 고도 자료에서 그대로 나온다 [확인]
  2. 산의 위치와 상대 높이: 백양산 637 m, 장산 627 m, 황령산 425 m [확인: 고도 자료]
  3. 정류장·명소 위치. OpenStreetMap 좌표 25곳 [확인]
  4. 하루마다 다른 색의 루트, 일정 순서대로 그려짐
- **생략·단순화할 것**
  1. 건물, 도로, 다리 모양 (광안대교·영도대교는 핀으로만)
  2. 도로를 정확히 따르는 경로 → 실제 버스가 지나는 주요 정류장을 이은 선으로 대신함 ("경로 개략")
  3. 바다 물결 (FX는 MAP08·편집 단계에서)
  4. 이름표 글자 (편집 단계 자막으로 넣는 것을 권장)

## 3. 치수표
| 부위 | 가로 X (unit) | 깊이 Y (unit) | 높이 Z (unit) | 근거 태그 | 근거·계산식 |
|---|---|---|---|---|---|
| 전체 지도 | 2.549 | 2.211 | 0.191 | [설정] 범위·축척 / [확인] 고도 | 실제 25.5 × 22.1 km, 1 unit = 10 km. 높이 = 637 m × 3배 ÷ 10 km |
| 지도 범위 | 남 35.05 / 서 128.98 / 북 35.25 / 동 129.26 | | | [설정] | 일정 전체 + 여백 |
| 핀 | 지름 0.02 | | 기둥 0.06 + 머리 | [설정] | 화면 1600 px 기준 핀 머리 약 12 px |
| 루트 선 | 반지름 0.004 | | 지면 위 0.004~0.010 | [설정] | 일차마다 0.003씩 높여 겹침 방지 |

- 1 unit = 실제 10 km라서 사람(1.70 m) 대비 비율은 의미가 없다(지도 축척).

## 6. 모델링 순서
| 단계 | 작업 | 설정값 |
|---|---|---|
| 1 | 고도 자료 처리 `dem_process.py` | 타일 2장 이어 붙이기 → 범위 자르기 → 0 m 미만은 0 m → 16비트 PNG |
| 2 | 지도 만들기 `map_build.py` | 높이 3배, 격자 300, 높이 이미지 Non-Color |
| 3 | 미리보기·저장 `build_export.py` | Cycles CPU 48샘플, `.blend`(이미지 포함), `.glb`(정지 모델) |

## 13. 확실하지 않은 값과 확인할 것
| 값 | 현재 | 태그 | 영향도 | 확인 방법 |
|---|---|---|---|---|
| 루트 모양 | 주요 정류장을 이은 직선 | [설정] | 중 | 도로를 따라야 하면 경유 정류장 추가 (남포역·수영역은 조회 제한으로 빠짐) |
| 부평깡통시장·차이나타운 핀 | 없음 | – | 하 | OpenStreetMap 좌표 찾으면 추가 |
| 높이 3배 과장 | 3.0 | [설정] | 중 | 연출에 따라 2~4 |
| 같은 길을 지나는 날의 루트 | 높이만 다르게 겹침 | [설정] | 하 | MAP07에서 이전 날 루트를 숨길지 결정 |

## 14. 실행 방법·결과
- 다시 만들기: `blender --background --python build_export.py`. 높이 이미지는 이미 들어 있으니 `dem_process.py`는 고도 자료를 바꿀 때만 실행한다.
- 결과: `BusanMap.blend` (애니메이션 포함, 높이 이미지 포함), `BusanMap.glb` (정지 모델), `previews/*.png`, `validation.json`
- 검증 기록: `validation.md`
