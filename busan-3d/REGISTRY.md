# 항목 레지스트리

버전: v2.0.0 — 2026-11-10 — 제작 방식별(3D / 실제 사진 / 일러스트)로 재구성

- **진행 순서:** 상태가 `대기`인 것을 우선순위 1 → 2 → 3 순서로, 같은 우선순위 안에서는 위쪽부터 진행한다.
- **상태:** `대기` → `초안`(기록·파일 저장) → `검토`(사용자 확인 중) → `확정`
- **폴더:** 3D는 `assets/`, 실제 사진은 `photos/`, 일러스트는 `images/` 아래에 `{ID}_{영문명}/`
- AI가 항목을 저장할 때마다 `상태`와 `버전`을 갱신한다. 빠진 항목은 해당 표 맨 아래에 추가하고 `주의`에 이유를 적는다.
- v1의 3D 모델 목록(VEH·ENV·SF·CHR·PRP·FOOD·FX)은 영상에 쓰지 않는다. 관광지·음식·실제 교통수단은 실제 사진(PH·FD)으로 바뀌었다. 이미 만든 v1 초안은 맨 아래 D표에 보관 기록이 있다.
