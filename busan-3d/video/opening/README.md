## 아직 임시인 것 (정직하게 표시함)
- **실제 사진 자리:** PH01, FD01, PH07은 점선 틀과 "실제 사진 자리" 글자만 있다. 사용권이 확인된 사진이 `photos/`에 올라오면 그 자리에 넣는다. 사진을 만들어 넣지 않았다.
- **탈것 아이콘:** MAP04 모델(`assets/MAP04_TransitTokens/TransitTokens.blend`)의 일반버스(61번)·KTX를 쓴다. 지도 배율은 설계도 0.08 대신 조정안 0.03 (MAP04 validation.md 3번) — 설계도 확정 전.
- **화질:** 3D는 960×540으로 렌더하고 글자는 1280×720으로 얹은 초안이다. 최종본은 100%로 다시 렌더한다(프레임당 약 7초).

## 다시 만들기
```
# 1) 3D 프레임 (Blender 4.2 이상, 약 40분)
blender --background --python opening_blender.py -- --out <프레임 폴더>
#    구도만 볼 때: ... -- --out <폴더> --stills   (timeline.json 의 check_frames 8장)
# 2) 글자·패널 얹고 mp4 (Pillow, ffmpeg, Noto Sans CJK 글꼴)
python opening_overlay.py --frames <프레임 폴더> --comp <합성 폴더> --out opening_v2.mp4
```
- 장면 시간, 카메라 위치, 문구는 `timeline.json` 한 곳에서 고친다.
- 지도는 `assets/MAP01_BusanMap/BusanMap.blend`를 그대로 불러오고, 이 영상에서만 다음을 바꾼다: 지형 부드러운 음영, 핀 0.6배, 2·3일차 루트 숨김.
